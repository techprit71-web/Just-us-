Private by design

Pairing uses a room code. Messages are synced through Firebase. For true end-to-end encryption, the app still needs client-side encryption, authenticated key exchange and strict Firestore/Storage rules.

Calls: WebRTC media is peer-to-peer when connectivity allows; signaling is exchanged through the room.

Photos: This build compresses images before sending. Production privacy should encrypt photos before storage.

Important: Firebase client configuration is not a secret. Security comes from authentication, rules and cryptography — never from hiding the config.
