A note from Just Us

Private by design

Messages, moments, and calls should belong to the two people using them. This interface is prepared for a client-side encrypted architecture.

Important: this starter does not pretend that a visual interface alone provides end-to-end encryption. Production E2EE must encrypt on the device before data is sent to the server, use authenticated key exchange, and keep the server from receiving plaintext.

The same principle applies to photos and other private content.
